WS:1 Рабочие пространства — Alt+1-9 для переключения
f → режим подсказок по ссылкам
j / k → скролл вниз / вверх
gg / G → наверх / вниз страницы
Ctrl+Shift+A → Tab Exposé — все вкладки на одном экране
Ctrl+Shift+F → Grep — поиск по всему, что вы читали
Ctrl+Shift+P → страница в PiP-окне поверх всего
Ctrl+Shift+T → вернуть закрытую вкладку
: → командная палитра

Зачем Vox?
Браузер для тех, кто живёт на клавиатуре и любит настраивать всё под себя.
⌨

Vim-клавиши

Режим подсказок (f), командная палитра (:), insert-режим (i), скролл j/k — прямо внутри страницы, как Vimium. Ctrl+W и другие хоткеи работают даже с фокуса на странице.

🗂

Рабочие пространства

В духе hyprland: Alt+1-9 переключает воркспейсы, у каждого свои вкладки — изолированные и независимые.

📁

Группы вкладок

Группируйте вкладки по цвету и имени. Сворачивание, назначение через контекстное меню.

новое
🌌

Aurora — адаптивный акцент

Браузер считывает доминантный цвет открытой страницы и подстраивает под него акцент интерфейса. Сайт становится частью браузера.

новое
▦

Tab Exposé

Ctrl+Shift+A — все вкладки сеткой на одном экране. Живой поиск, превью, закрытие и открытие без возврата к мышке.

новое
🔎

Grep по истории

Ctrl+Shift+F — полнотекстовый поиск по содержимому всех прочитанных страниц. Находите то, что видели неделю назад, по фразе из статьи.

новое
🖼

Страница в PiP-окне

Ctrl+Shift+P — текущая страница улетает в маленькое всегда-поверх окно. Смотрите видео и читайте одновременно.

новое
🗺

Session Trail

Карта пути по вкладке: каждый переход — точка на маршруте. Возвращайтесь на любой шаг в один клик.

новое
💤

Спящие вкладки

Фоновые вкладки автоматически замьючиваются и получают значок zZ. Никакого звука с закрытых сайтов.

новое
👓

Site Lenses

Настройки для конкретных сайтов: свой масштаб, тёмный режим и vim-клавиши на youtube.com и всё, что угодно.

новое
🕶

Инкогнито + Reopen

Ctrl+Shift+N — приватная вкладка без сохранения. Ctrl+Shift+T — возврат закрытой вкладки, даже после перезапуска.

🧭

Browser Chrome

Классическая панель с кнопками назад/вперёд, адресной строкой и заголовком — когда хочется «как в обычных браузерах».

🎨

80+ тем и пресеты

Классика, 10 супер-пресетов (Neon Aurora, Void Glass, Ember Forge...) и новые экспериментальные темы — включая вдохновлённую свежим дизайном Firefox Nightly.

🔧

Глубокая кастомизация

Шрифт, высоты панелей, радиус, скорость анимаций, прозрачность вкладок, фон NTP, 30+ настроек. Полностью русский + английский интерфейс.

новое в v1.3
🛍

Магазин расширений: 130 дополнений

Мега-каталог из 130 встроенных дополнений — от ad-block и ночного режима до калькулятора, QR-кодов, таймеров, снапшотов и приватности. Всё включается одним кликом (Ctrl+Shift+O), браузер остаётся лёгким.
