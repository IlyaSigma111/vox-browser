Why Vox?
A browser built for power users who live in the keyboard.
⌨

Vim Keybindings

Native hint mode (f), command palette (:), insert mode (i), scroll (j/k). All keys handled inside the page like Vimium.

🗂

Workspaces

Hyperland-style workspaces with Alt+1-9 switching. Each workspace has its own tabs, independent and isolated.

📁

Tab Groups

Group tabs by color and name. Collapse/expand, assign via context menu. Organize your browsing.

🎨

79+ Themes

24 trapezoid-bottom presets, 10 super-design presets (Neon Aurora, Void Glass, Ember Forge...), 45+ others. Full custom color picker.

◆

6 Tab Shapes

Square, Rounded, Pill, Trapezoid, Yandex-style, and Wave. Plus height, opacity, and radius controls.

🔧

Deep Customization

Font, bar heights, border radius, animation speed, tab opacity, NTP background color, workspace position. 30+ settings.

🌐

Russian + English

Full UI localization. Switch between English and Russian in settings. All labels, sections, and controls translated.

🔍

Find on Page

Ctrl+F to search within any page. Match counter, next/prev navigation. Glassmorphism overlay.

🧭

Browser Chrome Mode

Toggle a full browser toolbar with back/forward/reload, editable URL bar, and page title. Classic browser feel when you need it.

📌

Tab Pinning

Pin important tabs with right-click. Pinned tabs sort first as compact icon-only tabs. Middle-click to close.
